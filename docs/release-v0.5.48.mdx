## Changelog

### Features

- Claude plugin: write ai-ready Issues from a conversation and hand them to Orbi (/orbi:ship, /orbi:status) — listing gives a claude.com backlink ([Issue #1389](https://github.com/orbi-build/orbi/issues/1389); [PR #1390](https://github.com/orbi-build/orbi/pull/1390))

### Reliability and recovery

- Allow a release whose milestone has no deliveries (a new user's first release is blocked) ([Issue #1384](https://github.com/orbi-build/orbi/issues/1384); [PR #1387](https://github.com/orbi-build/orbi/pull/1387))
- Claude plugin reads active_milestone from the local working tree: a stale checkout files the Issue into a closed milestone and it is never claimed ([Issue #1395](https://github.com/orbi-build/orbi/issues/1395); [PR #1396](https://github.com/orbi-build/orbi/pull/1396))

### Bug fixes

- A closed active milestone with no newer milestone should mean no scope, so ai-ready Issues are claimed after the first release ([Issue #1391](https://github.com/orbi-build/orbi/issues/1391); [PR #1394](https://github.com/orbi-build/orbi/pull/1394))
