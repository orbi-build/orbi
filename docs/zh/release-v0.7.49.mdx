## Changelog

### Reliability and recovery

- Resume continues when the delivery PR branch was fast-forwarded on GitHub (e.g. "Update branch"), instead of failing as diverged ([Issue #2261](https://github.com/orbi-build/orbi/issues/2261); [PR #2262](https://github.com/orbi-build/orbi/pull/2262))

### Deployment and operations

- In-flight restart scan resumes only Issues this deployment started, not any ai-in-progress Issue ([Issue #2256](https://github.com/orbi-build/orbi/issues/2256); [PR #2258](https://github.com/orbi-build/orbi/pull/2258))

### Documentation

- Docs: clarify task-page titles and installation summaries ([Issue #2251](https://github.com/orbi-build/orbi/issues/2251); [PR #2252](https://github.com/orbi-build/orbi/pull/2252))

### Bug fixes

- An idle tick repeats identical GitHub reads within the same tick ([Issue #2218](https://github.com/orbi-build/orbi/issues/2218); [PR #2257](https://github.com/orbi-build/orbi/pull/2257))
- Open one fix Issue for a red base branch, not one per failing check, so its PR can turn the base green and merge ([Issue #2259](https://github.com/orbi-build/orbi/issues/2259); [PR #2260](https://github.com/orbi-build/orbi/pull/2260))
