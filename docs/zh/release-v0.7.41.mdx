## Changelog

### Features

- orbi suggest: the small-task preference is a caller input (--size <n>), not a built-in rule; already_suggested drops size ([Issue #2139](https://github.com/orbi-build/orbi/issues/2139); [PR #2146](https://github.com/orbi-build/orbi/pull/2146))
- prompts/prompt.md: drop Orbi's own MVP boundary (no database/queue/daemon) from the default implementer prompt for delivered repositories ([Issue #2142](https://github.com/orbi-build/orbi/issues/2142); [PR #2149](https://github.com/orbi-build/orbi/pull/2149))
- orbi suggest: the #2119 why check matches the engine's input paths, not the word context.json ([Issue #2143](https://github.com/orbi-build/orbi/issues/2143); [PR #2150](https://github.com/orbi-build/orbi/pull/2150))
- orbi suggest: already_suggested is scoped to the repository (the batch file records repo) ([Issue #2145](https://github.com/orbi-build/orbi/issues/2145); [PR #2151](https://github.com/orbi-build/orbi/pull/2151))
- `orbi draft` accepts a bare-string question and a question without `header` or `options`, returns them as `{"question": "..."}` objects, and does not validate where the `(Recommended)` option sits; no code, prompt, tool description or round-document text refers to a hosted page, preselection or an "Other" row added by a page. ([Issue #2147](https://github.com/orbi-build/orbi/issues/2147); [PR #2152](https://github.com/orbi-build/orbi/pull/2152))
- The engine drafting rules and the write-ai-ready-issue skill agree: the full-form Issue body no longer asks for the commit line at the top, and both state that an Assumptions section appears only when at least one decision was taken. ([Issue #2148](https://github.com/orbi-build/orbi/issues/2148); [PR #2153](https://github.com/orbi-build/orbi/pull/2153))
