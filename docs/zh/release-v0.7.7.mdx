## 模型凭据与 GitHub 故障

本版修复了几类故障的归类偏差。模型 API 密钥缺失时，Orbi 报告凭据问题；发布检查遇到 GitHub 限流，或 GitHub CLI 请求超时时，Orbi 报告 GitHub 临时故障。改动见 [PR #1770](https://github.com/orbi-build/orbi/pull/1770)。

当前故障原因与处理办法见[工作流说明](/zh/workflow)；模型凭据与配置见[上手指南](/zh/getting-started)。
