## Changelog

### Features

- End problem alerts with one short help line instead of the full community sentence ([Issue #2289](https://github.com/orbi-build/orbi/issues/2289); [PR #2291](https://github.com/orbi-build/orbi/pull/2291))

### Reliability and recovery

- Telegram blocked/needs-detail alert names the reason, the next action, whether Orbi resumes, and links the stop comment ([Issue #2287](https://github.com/orbi-build/orbi/issues/2287); [PR #2290](https://github.com/orbi-build/orbi/pull/2290))
- Stop resuming a delivery whose same failure repeats 3 rounds in a row and end it in ai-blocked ([Issue #2292](https://github.com/orbi-build/orbi/issues/2292); [PR #2296](https://github.com/orbi-build/orbi/pull/2296))
- Resume: yield instead of ai-blocking when another executor's run is live ([Issue #2299](https://github.com/orbi-build/orbi/issues/2299); [PR #2310](https://github.com/orbi-build/orbi/pull/2310))

### Documentation

- Clarify self-hosted docs and fix the workflow diagram ([PR #2301](https://github.com/orbi-build/orbi/pull/2301))

### Bug fixes

- Post the plan-ready milestone at most once per run ([Issue #2293](https://github.com/orbi-build/orbi/issues/2293); [PR #2294](https://github.com/orbi-build/orbi/pull/2294))
- Stop the engine re-reading its own /orbi answer rejection receipt as a new answer ([Issue #2295](https://github.com/orbi-build/orbi/issues/2295); [PR #2300](https://github.com/orbi-build/orbi/pull/2300))
- Fresh claim: yield when another executor already started this Issue ([Issue #2298](https://github.com/orbi-build/orbi/issues/2298); [PR #2306](https://github.com/orbi-build/orbi/pull/2306))
