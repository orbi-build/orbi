## Changelog

### Features

- Telegram test notification says that the bot only sends alerts and replies are not read ([Issue #2288](https://github.com/orbi-build/orbi/issues/2288); [PR #2322](https://github.com/orbi-build/orbi/pull/2322))
- Constitution: Article 6.3 lets the Runner continue a delivery it claimed after the dispatch label is removed ([Issue #2308](https://github.com/orbi-build/orbi/issues/2308); [PR #2323](https://github.com/orbi-build/orbi/pull/2323))
- CI failure on branch main ([Issue #2316](https://github.com/orbi-build/orbi/issues/2316); [PR #2318](https://github.com/orbi-build/orbi/pull/2318))

### Reliability and recovery

- ai-ready means queued: the claim removes the dispatch label, interrupted runs resume by ai-in-progress ([Issue #2309](https://github.com/orbi-build/orbi/issues/2309); [PR #2324](https://github.com/orbi-build/orbi/pull/2324))

### Documentation

- Remove the repository CI failure workflow and the Groq docs catalog check; the engine opens the one fix Issue for a red main ([Issue #2319](https://github.com/orbi-build/orbi/issues/2319); [PR #2321](https://github.com/orbi-build/orbi/pull/2321))

### Bug fixes

- orbi draft: the draft tools return rule violations to the model so it corrects them in the same session ([Issue #2303](https://github.com/orbi-build/orbi/issues/2303); [PR #2314](https://github.com/orbi-build/orbi/pull/2314))
- A delivery waiting for checks before merge says so on its Issue: which commit's checks, and that Orbi merges once they pass ([Issue #2304](https://github.com/orbi-build/orbi/issues/2304); [PR #2320](https://github.com/orbi-build/orbi/pull/2320))
- A delivery that passed review and only waits for its checks is merged before the runner claims a new ready Issue (bounded exception to #1473) ([Issue #2305](https://github.com/orbi-build/orbi/issues/2305); [PR #2315](https://github.com/orbi-build/orbi/pull/2315))
- CI failure: tests on branch main (push) ([Issue #2313](https://github.com/orbi-build/orbi/issues/2313); [PR #2317](https://github.com/orbi-build/orbi/pull/2317))
