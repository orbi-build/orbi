## Changelog

### Features

- Pass run fields as fields instead of a "k=v k=v" string that is split back ([Issue #2055](https://github.com/orbi-build/orbi/issues/2055); [PR #2062](https://github.com/orbi-build/orbi/pull/2062))
- Failure comment Diagnosis shows the run correlation once ([Issue #2057](https://github.com/orbi-build/orbi/issues/2057); [PR #2064](https://github.com/orbi-build/orbi/pull/2064))
- Document the suggest run's understanding session directory in the public contract ([Issue #2058](https://github.com/orbi-build/orbi/issues/2058); [PR #2065](https://github.com/orbi-build/orbi/pull/2065))

### Reliability and recovery

- Keep the resume scene as one Scene value from comment to next scene block ([Issue #2053](https://github.com/orbi-build/orbi/issues/2053); [PR #2061](https://github.com/orbi-build/orbi/pull/2061))
- Use one spelling for the recoverable failure outcome ("fix_needed") ([Issue #2056](https://github.com/orbi-build/orbi/issues/2056); [PR #2063](https://github.com/orbi-build/orbi/pull/2063))

### Bug fixes

- orbi draft: the fidelity pass drops outcomes from earlier rounds because it only sees the latest message ([Issue #2050](https://github.com/orbi-build/orbi/issues/2050); [PR #2059](https://github.com/orbi-build/orbi/pull/2059))
- English status comments repeat their headline as a "- detail:" row ([Issue #2054](https://github.com/orbi-build/orbi/issues/2054); [PR #2060](https://github.com/orbi-build/orbi/pull/2060))
