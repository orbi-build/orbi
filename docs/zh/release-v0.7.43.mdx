## Changelog

### Features

- Runner reports a missing prompt file as a one-line config_invalid diagnostic instead of a traceback ([Issue #2179](https://github.com/orbi-build/orbi/issues/2179); [PR #2181](https://github.com/orbi-build/orbi/pull/2181))
- Pi prerequisite check has one probe and one validity rule for pi_executable ([Issue #2188](https://github.com/orbi-build/orbi/issues/2188); [PR #2191](https://github.com/orbi-build/orbi/pull/2191))

### Reliability and recovery

- New host config key pi_executable selects which Pi executable Orbi starts ([Issue #2182](https://github.com/orbi-build/orbi/issues/2182); [PR #2183](https://github.com/orbi-build/orbi/pull/2183))

### Deployment and operations

- Read-only commands list installed deployment configs when the local orbi.toml is invalid ([Issue #2190](https://github.com/orbi-build/orbi/issues/2190); [PR #2193](https://github.com/orbi-build/orbi/pull/2193))

### Documentation

- Docs: describe pi_executable generically instead of naming pi-bolt ([Issue #2189](https://github.com/orbi-build/orbi/issues/2189); [PR #2192](https://github.com/orbi-build/orbi/pull/2192))
