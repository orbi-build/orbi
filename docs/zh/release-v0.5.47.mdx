## Changelog

### Features

- Runner-side git calls execute repository-selected programs (core.fsmonitor, hooksPath, filter drivers): neutralise them in one helper ([Issue #1366](https://github.com/orbi-build/orbi/issues/1366); [PR #1368](https://github.com/orbi-build/orbi/pull/1368))
- Remove tests that pin marketing wording or dates (#1331, #1348) ([Issue #1378](https://github.com/orbi-build/orbi/issues/1378); [PR #1381](https://github.com/orbi-build/orbi/pull/1381))

### Reliability and recovery

- Resumed runs should update their progress comment, not post a new 'Orbi started Pi' comment each time ([Issue #1369](https://github.com/orbi-build/orbi/issues/1369); [PR #1372](https://github.com/orbi-build/orbi/pull/1372))
- Log Codex 'usage limit has been reached' as provider_quota at the Pi exit (no other behavior change) ([Issue #1374](https://github.com/orbi-build/orbi/issues/1374); [PR #1375](https://github.com/orbi-build/orbi/pull/1375))
- Thin-ticket gate: remove ai-needs-detail on claim, one shared Pi helper with a timeout, smaller verdict and tests ([Issue #1379](https://github.com/orbi-build/orbi/issues/1379); [PR #1380](https://github.com/orbi-build/orbi/pull/1380))

### Deployment and operations

- Stagger drop-in self-heal ping-pongs between deployments sharing a unit dir and re-enables disabled timers ([Issue #1362](https://github.com/orbi-build/orbi/issues/1362); [PR #1364](https://github.com/orbi-build/orbi/pull/1364))
- orbi setup fails on every retry: its own .orbi/ runtime dir makes the checkout 'not clean' ([Issue #1367](https://github.com/orbi-build/orbi/issues/1367); [PR #1370](https://github.com/orbi-build/orbi/pull/1370))
- Replace the timer stagger drop-ins (#1330/#1354/#1364) with RandomizedDelaySec + FixedRandomDelay; keep the self-heal enable guard ([Issue #1377](https://github.com/orbi-build/orbi/issues/1377); [PR #1382](https://github.com/orbi-build/orbi/pull/1382))

### Bug fixes

- Release-page test fails on every release tag commit (page lands one commit later) ([Issue #1363](https://github.com/orbi-build/orbi/issues/1363); [PR #1365](https://github.com/orbi-build/orbi/pull/1365))
