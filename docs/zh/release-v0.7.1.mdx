## Changelog

### Features

- Identify delivery comments and review rounds without English headings ([Issue #1659](https://github.com/orbi-build/orbi/issues/1659); [PR #1679](https://github.com/orbi-build/orbi/pull/1679))
- Support a global message language with an explicit repository override ([Issue #1660](https://github.com/orbi-build/orbi/issues/1660); [PR #1681](https://github.com/orbi-build/orbi/pull/1681))
- orbi suggest --count N: ask for at most N suggestions ([Issue #1671](https://github.com/orbi-build/orbi/issues/1671); [PR #1680](https://github.com/orbi-build/orbi/pull/1680))
- Telegram message when Orbi puts a task into a state that waits for a person ([Issue #1673](https://github.com/orbi-build/orbi/issues/1673); [PR #1678](https://github.com/orbi-build/orbi/pull/1678))
- Telegram message when a PR Orbi opened is merged, whoever merged it ([Issue #1674](https://github.com/orbi-build/orbi/issues/1674); [PR #1682](https://github.com/orbi-build/orbi/pull/1682))

### Reliability and recovery

- orbi status hangs when a single-Issue, ready-queue or result read stalls: only the open-Issue listing has a timeout ([Issue #1668](https://github.com/orbi-build/orbi/issues/1668); [PR #1675](https://github.com/orbi-build/orbi/pull/1675))
- orbi status lists an Issue a maintainer labelled ai-blocked mid-delivery as an active delivery ([Issue #1669](https://github.com/orbi-build/orbi/issues/1669); [PR #1672](https://github.com/orbi-build/orbi/pull/1672))

### Observability

- Finished progress comments lose the formal prefix: the outcome text is rendered before the run marker ([Issue #1667](https://github.com/orbi-build/orbi/issues/1667); [PR #1676](https://github.com/orbi-build/orbi/pull/1676))

### Documentation

- docs: align English and Chinese product definitions with software dark factory ([Issue #1665](https://github.com/orbi-build/orbi/issues/1665); [PR #1666](https://github.com/orbi-build/orbi/pull/1666))
