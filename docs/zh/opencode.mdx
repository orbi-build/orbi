# OpenCode provider

OpenCode 是 **Pi 原生支持**的 provider。本页记录 **2026-09-07 使用 Pi
0.85.1** 的实测；OpenCode 的目录、套餐和限额可能变化。本页属于
[#305](https://github.com/orbi-build/orbi/issues/305) provider 文档 Epic。

## 已实际验证的结果

已安装的 Pi CLI 报告 OpenCode 使用 `OPENCODE_API_KEY`，内置 provider id
是 `opencode`，并包含下面的模型目录。在本次验证账号上运行
`timeout 30 pi auth check --provider opencode --json --no-refresh` 返回：

```json
{"status":"not_ready","provider":"opencode","reason":"credentials_not_configured"}
```

因此本工作区**不声称** OpenCode 请求成功、消耗了额度或创建了 Orbi PR。
只有拥有 OpenCode 凭据的账号真正跑通后，才能补充 delivery 证据；不能把
z.ai 或 Gemini 的耗时、额度数字套到 OpenCode 上。

## 认证

1. 在拥有目标额度的 OpenCode 账号/套餐中取得 API key。key 必须留在 Git、
   Issue、journal 和 PR 文本之外。
2. 手工检查时导出 key，或将它放入 Orbi systemd unit 加载的私有环境文件：

   ```bash
   export OPENCODE_API_KEY='...'
   timeout 30 pi auth check --provider opencode --json
   ```

3. Pi 0.85.1 文档化的 CLI 命令是 `pi auth check`、`print-api-key` 和
   `print-bearer-token`；没有针对 OpenCode 的 `/login` 流程。实测认证契约
   是 API key，不是 OAuth。若未来 Pi 改变行为，必须重新运行上述命令并先
   更新本文档，不能凭 provider 名称推断。

## 目录与 Orbi 配置

目录由 Pi 原生维护，所以 OpenCode **不要创建或复制
`pi_providers.json` 条目**。另写一个 OpenAI-compatible endpoint 会固定过期
的模型元数据，不是原生路径。在 `orbi.toml` 只设置选择项：

```toml
pi_provider = "opencode"
pi_model = "glm-5.3-flash"
```

## 额度、限流、重置和错误

本次实测没有认证 OpenCode 账号，因此这里有意**不写任何数字额度、限流、
重置时间或套餐承诺**。预算运行前应查看 OpenCode 账号当前套餐。无效或过期
key 在 Pi 中可由 `pi auth check` 观察到 `credentials_not_configured`；上游
额度或限流错误必须来自真实 Pi/Orbi journal，并保留 HTTP 状态码和 provider
消息。不能从模型名推断重置行为。

真实 delivery 完成后，应在本文或关联 Issue 补充日期、账号/套餐边界（不含
secret）、journal 的 `provider` 与 `model`、`run_id`、PR URL 和耗时。本工作区
目前没有这些证据。

## 真实 Orbi delivery 清单

认证后，在用户自己的仓库跑一个小 Issue，记录 journal 中的
`provider=opencode model=<id>`、Orbi 稳定 `run_id`、PR URL 和耗时秒数。
只有 `pi auth check` 不足以证明 delivery。API key 不得进入任何产物。

## 最小切换方案

保持 Orbi runner 不变。切到 z.ai 时，将已有 `z-ai.json` 模板复制为
`.orbi/pi-providers.json`，并将 `ZAI_API_KEY` 放入 `.orbi/env`；完整的选择项
变更如下：

```diff
+pi_providers = ".orbi/pi-providers.json"
-pi_provider = "opencode"
-pi_model = "glm-5.3-flash"
+pi_provider = "z-ai"
+pi_model = "glm-5.3-flash"
```

切到本地 Qwen 时使用已有 `local-qwen.json` 模板，并选择它实际宣告的精确
model id；不要复用 OpenCode 的 model id。参见[provider 模板](/zh/providers)
和[上手指南](/zh/getting-started)。
