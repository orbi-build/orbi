## Changelog

### Features

- Problem messages end with a link to the Orbi community chat; the human-review wait also notifies ([Issue #1684](https://github.com/orbi-build/orbi/issues/1684); [PR #1689](https://github.com/orbi-build/orbi/pull/1689))
- orbi suggest: already_suggested should cover the whole previous batch when a caller splits it across runs ([Issue #1685](https://github.com/orbi-build/orbi/issues/1685); [PR #1720](https://github.com/orbi-build/orbi/pull/1720))
- Delivery comment bodies follow the repository's language, without local paths ([Issue #1702](https://github.com/orbi-build/orbi/issues/1702); [PR #1712](https://github.com/orbi-build/orbi/pull/1712))
- Health-check comment uses the repository's message language ([Issue #1703](https://github.com/orbi-build/orbi/issues/1703); [PR #1710](https://github.com/orbi-build/orbi/pull/1710))
- Milestone confirmation and /command receipts follow the repository's language ([Issue #1704](https://github.com/orbi-build/orbi/issues/1704); [PR #1709](https://github.com/orbi-build/orbi/pull/1709))
- Epic reconciliation comment follows the repository's language ([Issue #1705](https://github.com/orbi-build/orbi/issues/1705); [PR #1708](https://github.com/orbi-build/orbi/pull/1708))
- A failure comment over the size limit keeps its structure: shrink the evidence, never cut the comment ([Issue #1711](https://github.com/orbi-build/orbi/issues/1711); [PR #1716](https://github.com/orbi-build/orbi/pull/1716))
- The "Orbi started Pi" comment no longer shows the runner's worktree path ([Issue #1715](https://github.com/orbi-build/orbi/issues/1715); [PR #1717](https://github.com/orbi-build/orbi/pull/1717))

### Reliability and recovery

- Keep the community help line visible when a long blocked failure comment is cut ([Issue #1695](https://github.com/orbi-build/orbi/issues/1695); [PR #1700](https://github.com/orbi-build/orbi/pull/1700))
- Notification module clean-up: remove a dead assignment, tests through the public surface ([Issue #1698](https://github.com/orbi-build/orbi/issues/1698); [PR #1718](https://github.com/orbi-build/orbi/pull/1718))
- Review-stage blocked comments say why and how to resume, in the repository's language ([Issue #1701](https://github.com/orbi-build/orbi/issues/1701); [PR #1713](https://github.com/orbi-build/orbi/pull/1713))
- Failed-delivery progress comments and the resume-blocked comment no longer show the runner's local paths ([Issue #1721](https://github.com/orbi-build/orbi/issues/1721); [PR #1723](https://github.com/orbi-build/orbi/pull/1723))
- The resume-blocked comment ends with the community help line ([Issue #1722](https://github.com/orbi-build/orbi/issues/1722); [PR #1726](https://github.com/orbi-build/orbi/pull/1726))
- Blocked comments give one working unblock step: the scene-missing messages no longer say "or relabel ai-fix-needed" ([Issue #1724](https://github.com/orbi-build/orbi/issues/1724); [PR #1725](https://github.com/orbi-build/orbi/pull/1725))

### Observability

- Log a journal line when the merged-PR notification check cannot run ([Issue #1696](https://github.com/orbi-build/orbi/issues/1696); [PR #1699](https://github.com/orbi-build/orbi/pull/1699))

### Documentation

- Notifications docs: correct the token and chat-id wording ([Issue #1697](https://github.com/orbi-build/orbi/issues/1697); [PR #1714](https://github.com/orbi-build/orbi/pull/1714))

### Bug fixes

- orbi notify test shows Telegram's reason and the community help line ([Issue #1686](https://github.com/orbi-build/orbi/issues/1686); [PR #1707](https://github.com/orbi-build/orbi/pull/1707))
- Localize every delivery comment by the repository's message_language, and seed the key at the top level ([Issue #1687](https://github.com/orbi-build/orbi/issues/1687); [PR #1692](https://github.com/orbi-build/orbi/pull/1692))
- orbi suggest --count N: keep the first N before validating, so an invalid extra entry cannot fail the run ([Issue #1688](https://github.com/orbi-build/orbi/issues/1688); [PR #1690](https://github.com/orbi-build/orbi/pull/1690))
- Send the human-review "waiting for your review" message where the checklist is built; keep the help line on cut failure comments ([Issue #1691](https://github.com/orbi-build/orbi/issues/1691); [PR #1706](https://github.com/orbi-build/orbi/pull/1706))
- orbi suggest --locale zh: unescaped ASCII quotes in Chinese text break the JSON answer ([Issue #1693](https://github.com/orbi-build/orbi/issues/1693); [PR #1694](https://github.com/orbi-build/orbi/pull/1694))
