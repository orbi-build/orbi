## Release notes

## Changelog

### Features

- A missing base branch is detected by asking the remote, not by matching Git's error text ([Issue #1756](https://github.com/orbi-build/orbi/issues/1756); [PR #1761](https://github.com/orbi-build/orbi/pull/1761))
- Git errors are recognised the same way in any system language ([Issue #1758](https://github.com/orbi-build/orbi/issues/1758); [PR #1767](https://github.com/orbi-build/orbi/pull/1767))
- A failure that merely mentions "N failed" is no longer reported as a test failure ([Issue #1759](https://github.com/orbi-build/orbi/issues/1759); [PR #1763](https://github.com/orbi-build/orbi/pull/1763))
- Failed GitHub requests are classified by HTTP status, not by error text ([Issue #1760](https://github.com/orbi-build/orbi/issues/1760); [PR #1762](https://github.com/orbi-build/orbi/pull/1762))
- Chinese suggestion bodies use Chinese section headings ([Issue #1764](https://github.com/orbi-build/orbi/issues/1764); [PR #1765](https://github.com/orbi-build/orbi/pull/1765))

### Reliability and recovery

- The missing-base-branch blocked comment says what is wrong, where to fix it and how to restart ([Issue #1753](https://github.com/orbi-build/orbi/issues/1753); [PR #1757](https://github.com/orbi-build/orbi/pull/1757))

### Documentation

- docs: an awaiting-merge PR also waits for the runner's other repositories ([PR #1755](https://github.com/orbi-build/orbi/pull/1755))
- docs: mark tests_failed as a legacy reason code ([PR #1766](https://github.com/orbi-build/orbi/pull/1766))
