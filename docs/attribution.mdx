# Attribution tokens

Maintainers must add the matching `ref` token when sharing the Cloud CTA manually. Tokens are lowercase, flat, and use a prefix for the channel; keep them within the existing 32-character token limit.

| Token pattern | Use for |
| --- | --- |
| `gh-readme` | GitHub repository README CTA |
| `gh-issue` | Links pasted in an Issue or Discussion |
| `docs-<page>` | A page on docs.orbi.build, such as `docs-getting-started` |
| `x-<yymmdd>` | An X post, with the date identifying the post |
| `hn-<postid>` | A Hacker News post |
| `tg` | A Telegram group |
| `email-<batch>` | An email batch |

Example: `https://orbi.build/cloud/?ref=x-260919`.
