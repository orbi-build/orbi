These notes describe a historical self-hosted core release. Availability in Orbi Cloud depends on its deployed version.

## Credential and GitHub failures

This release restores the error classification used before v0.7.6. Orbi reports a missing model API key as a credential problem. It classifies GitHub rate limits during release checks and GitHub CLI network timeouts as transient GitHub failures. The changes are in [PR #1770](https://github.com/orbi-build/orbi/pull/1770).

For current failure reasons and recovery actions, read the [workflow guide](/workflow). For model credentials and configuration, use the [getting-started guide](/getting-started).
