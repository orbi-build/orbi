## Changelog

### Features

- orbi draft: a question with a recommended option is answered by the engine, not sent to the person ([Issue #2198](https://github.com/orbi-build/orbi/issues/2198); [PR #2204](https://github.com/orbi-build/orbi/pull/2204))
- Re-queue once automatically after a transient GitHub failure before the PR exists ([Issue #2202](https://github.com/orbi-build/orbi/issues/2202); [PR #2208](https://github.com/orbi-build/orbi/pull/2208))
- Base branch CI red: the engine opens the fix Issue itself instead of waiting for /orbi fix-base ([Issue #2203](https://github.com/orbi-build/orbi/issues/2203); [PR #2209](https://github.com/orbi-build/orbi/pull/2209))
- A failing clarification verdict with a usable split proposal creates the child tickets linked and queued, marks the parent ai-epic without delivering it, and posts one comment listing the children. ([Issue #2207](https://github.com/orbi-build/orbi/issues/2207); [PR #2213](https://github.com/orbi-build/orbi/pull/2213))

### Reliability and recovery

- orbi draft: an explicit request not to change code ends the round with a reply and no Issue ([Issue #2201](https://github.com/orbi-build/orbi/issues/2201); [PR #2205](https://github.com/orbi-build/orbi/pull/2205))
- A failing clarification verdict with a usable criteria proposal appends the proposed acceptance conditions under the acceptance heading, adds no ai-needs-detail, and the same claim proceeds to delivery with one comment listing what was added and noting that editing the ticket changes them. ([Issue #2206](https://github.com/orbi-build/orbi/issues/2206); [PR #2212](https://github.com/orbi-build/orbi/pull/2212))

### Documentation

- Docs: note in the pi_executable row that Pi-Bolt has run real deliveries (#2182) ([Issue #2194](https://github.com/orbi-build/orbi/issues/2194); [PR #2196](https://github.com/orbi-build/orbi/pull/2196))
- Docs: describe the merge gate's base-update case instead of "only the reviewed head merges" ([Issue #2195](https://github.com/orbi-build/orbi/issues/2195); [PR #2197](https://github.com/orbi-build/orbi/pull/2197))

### Bug fixes
