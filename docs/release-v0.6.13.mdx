## Changelog

### Features

- Engine prompts and activity display name pytest in rules that apply to every repository: make them framework-neutral ([Issue #1616](https://github.com/orbi-build/orbi/issues/1616); [PR #1624](https://github.com/orbi-build/orbi/pull/1624))
- Shared prompts impose orbi's own coverage policy (#234) on every repository: take coverage requirements from the repository itself ([Issue #1617](https://github.com/orbi-build/orbi/issues/1617); [PR #1619](https://github.com/orbi-build/orbi/pull/1619))
- orbi suggest --locale zh|en: write suggestions and the repository summary in the caller's language ([Issue #1620](https://github.com/orbi-build/orbi/issues/1620); [PR #1622](https://github.com/orbi-build/orbi/pull/1622))
- Remove the negative "tiered" / "issue #234" assertions added by #1619 from the prompt contract tests ([Issue #1621](https://github.com/orbi-build/orbi/issues/1621); [PR #1623](https://github.com/orbi-build/orbi/pull/1623))

### Bug fixes

- Report test status from the PR's GitHub Actions checks only: stop parsing local test logs and stop prescribing how the agent tests (#805) ([Issue #1613](https://github.com/orbi-build/orbi/issues/1613); [PR #1618](https://github.com/orbi-build/orbi/pull/1618))
