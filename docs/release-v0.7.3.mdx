## Changelog

### Features

### Reliability and recovery

- Move bootstrap Pi session and recovery tests into their own domain suite ([Issue #1646](https://github.com/orbi-build/orbi/issues/1646); [PR #1740](https://github.com/orbi-build/orbi/pull/1740))
- Every blocked comment ends with the community help line, added once at a shared exit ([Issue #1730](https://github.com/orbi-build/orbi/issues/1730); [PR #1732](https://github.com/orbi-build/orbi/pull/1732))

### Observability

- After the PR opens, the progress comment says it is waiting for checks and review ([Issue #1733](https://github.com/orbi-build/orbi/issues/1733); [PR #1735](https://github.com/orbi-build/orbi/pull/1735))

### Bug fixes

- Chinese repositories still see English in Orbi's delivery comments and PR body ([Issue #1729](https://github.com/orbi-build/orbi/issues/1729); [PR #1739](https://github.com/orbi-build/orbi/pull/1739))
- Review scan takes the oldest open deliveries first, so the earliest PR is not starved by newer ones ([Issue #1734](https://github.com/orbi-build/orbi/issues/1734); [PR #1737](https://github.com/orbi-build/orbi/pull/1737))
- Merge gate re-reads a briefly UNKNOWN mergeability within the tick instead of deferring a whole tick ([Issue #1736](https://github.com/orbi-build/orbi/issues/1736); [PR #1738](https://github.com/orbi-build/orbi/pull/1738))
