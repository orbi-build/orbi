## Release notes

## Changelog

### Features

- Support retention of terminally failed delivery worktrees and complete local evidence ([Issue #2175](https://github.com/orbi-build/orbi/issues/2175); [PR #2178](https://github.com/orbi-build/orbi/pull/2178))

### Reliability and recovery

- tools/size_ratchet.py applies the 1,000-line SIZE_CAP only to modules absent from the baseline, while modules that already exist are checked against their recorded length, which may go down but never up; the per-function ratchet and runner_top_level_defs ratchet are unchanged. ([Issue #2167](https://github.com/orbi-build/orbi/issues/2167); [PR #2169](https://github.com/orbi-build/orbi/pull/2169))
- runner.py::_dispatch_implementation is split into one private function per scene (fresh claim, restart in flight, external takeover, ops) plus one shared closeout, with the public entry keeping its signature and dispatching by scene, no logic, message or label change, and no new function over 100 lines. ([Issue #2168](https://github.com/orbi-build/orbi/issues/2168); [PR #2171](https://github.com/orbi-build/orbi/pull/2171))

### Documentation

- Release docs pages break the Mintlify build when a changelog line contains &lt;…> or &#123;…&#125; ([Issue #2154](https://github.com/orbi-build/orbi/issues/2154); [PR #2155](https://github.com/orbi-build/orbi/pull/2155))
- Release docs: preserve literal code contents across Markdown line breaks ([Issue #2156](https://github.com/orbi-build/orbi/issues/2156); [PR #2157](https://github.com/orbi-build/orbi/pull/2157))
- Release docs: prevent MDX parse errors at Setext headings ([Issue #2158](https://github.com/orbi-build/orbi/issues/2158); [PR #2159](https://github.com/orbi-build/orbi/pull/2159))
- Release docs: preserve code spans across list continuation lines ([Issue #2160](https://github.com/orbi-build/orbi/issues/2160); [PR #2161](https://github.com/orbi-build/orbi/pull/2161))
- Release docs: fix MDX parsing after lists or quotes and a JSX flow block ([Issue #2162](https://github.com/orbi-build/orbi/issues/2162); [PR #2163](https://github.com/orbi-build/orbi/pull/2163))
- Release docs: preserve inline code containing indented list-like JSX text ([Issue #2164](https://github.com/orbi-build/orbi/issues/2164); [PR #2166](https://github.com/orbi-build/orbi/pull/2166))
- Release docs: close paragraph state at headings inside lists and block quotes ([Issue #2170](https://github.com/orbi-build/orbi/issues/2170); [PR #2172](https://github.com/orbi-build/orbi/pull/2172))
- Release docs: escape literal text after headings inside mixed list/quote markers ([Issue #2173](https://github.com/orbi-build/orbi/issues/2173); [PR #2174](https://github.com/orbi-build/orbi/pull/2174))
- README: the Website link in the links row carries no ?ref=, so its visits can't be attributed ([Issue #2176](https://github.com/orbi-build/orbi/issues/2176); [PR #2177](https://github.com/orbi-build/orbi/pull/2177))
