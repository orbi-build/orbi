### Deployment and operations

- Pi has no install instruction and no stated Node floor: npm install succeeds on Node 20 and every pi call then crashes ([Issue #1079](https://github.com/orbi-build/orbi/issues/1079); [PR #1083](https://github.com/orbi-build/orbi/pull/1083))
- install.sh does not install Pi: the install reports success and every tick then fails at the first Pi call ([Issue #1080](https://github.com/orbi-build/orbi/issues/1080); [PR #1082](https://github.com/orbi-build/orbi/pull/1082))
